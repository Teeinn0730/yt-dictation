怎麼複製 YouTube 的轉錄稿？（電腦版）
  1. 在 YouTube 影片下方的說明欄點「…更多」，往下捲到「顯示轉錄稿」並點開。
  2. 右側出現轉錄稿面板後，確認語言是英文。
  3. 從第一行拖曳選取到最後一行，按 Ctrl+C 複製，貼到下面的框框。
  4. 手機的 YouTube App 無法複製轉錄稿，請改用「✨ Gemini 自動產生」。
  5. 也可以貼 .srt／.vtt 字幕檔的內容。

Gemini 會直接「看」這部影片並產生有時間軸的字幕，適合沒有字幕或在手機上使用。只支援公開影片；影片越長越耗免費額度，所以一次處理一段時間。時間軸大約只準到 1 秒左右。

        Gemini API 金鑰（免費）

        不需要訂閱任何方案，也不用綁信用卡。

        1. 用你的 Google 帳號打開 Google AI Studio 的 API 金鑰頁面。
        2. 按「Create API key」（建立 API 金鑰）。
        3. 複製金鑰（開頭通常是 AIza），貼到下面並按「儲存」。

        🔒 金鑰只存在這台裝置的瀏覽器裡，只會直接傳給 Google。換裝置要重新貼一次。
        ⚠️ 免費方案的內容可能被 Google 用來改善模型，請不要輸入私人資料。

        按「取得可用模型」會自動選好推薦的模型（flash 系列，免費額度較多）。模型被 Google 淘汰時，程式也會自動換成可用的模型。

        打字音效

        上傳一段打字的錄音（mp3、wav、m4a 都可以，幾秒到十幾秒最好）。程式會自動切出每一下按鍵聲，打字時隨機播放，聽起來就跟原音一樣。
        音檔來源：可以用手機錄自己的鍵盤，或到 Pixabay、Freesound 這類網站找標示「可免費使用」的鍵盤音效。
